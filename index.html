⚙️ Automatic Cloud Sync Setup

Set up automatic syncing so your data stays perfectly in sync across all devices! (5 minutes)

Step 1: Create a GitHub Gist
- Go to gist.github.com and sign in
- Create new Gist with filename: vehicle-logs.json
- Content:
{"logs":[]}
- Click "Create secret gist"
- Copy the Gist ID from URL (e.g., abc123def456...)

Step 2: Create a GitHub Token (for automatic sync)
- Go to github.com/settings/tokens/new
- Note: "Vehicle Log App"
- Expiration: "No expiration" (or 1 year)
- Check only: ✅ gist (under Select scopes)
- Click "Generate token" at bottom
- Copy the token (starts with ghp_...)
- ⚠️ Save it now - you can't see it again!
This stays private in your browser. Never share it!

❓ Help & Documentation

📚 Quick Start

This app helps you track vehicle maintenance across all your family vehicles with automatic cloud syncing.

🚗 Adding a Log

  1. Click the "➕ Add Log" button
  2. Enter vehicle name, date (defaults to today), and odometer
  3. Add notes about what was done
  4. Click "Save" - it syncs automatically!

💡 Tip: Change the date to add historical records from the past!

✏️ Editing a Log

  1. Find the log entry you want to edit
  2. Click the "✏️ Edit" button
  3. Confirm that you want to edit
  4. Make your changes and click "Save Changes"

📝 Note: Edited entries show "Last edited" timestamp at the bottom.

🗑️ Deleting a Log

  1. Find the log entry you want to remove
  2. Click the "🗑️ Delete" button at the bottom
  3. Confirm the deletion
  4. Entry is removed and synced automatically!

🔄 Syncing

Automatic Mode: If you entered a GitHub token, everything syncs automatically!

  • Add logs → auto-uploads to cloud
  • Edit logs → auto-syncs changes
  • Delete logs → auto-syncs changes
  • Open app → auto-loads latest data
  • Click 🔄 Sync for manual refresh

📊 Analysis Mode

  1. Click the "📊 Analysis" button in the header
  2. Select a vehicle from the dropdown
  3. View odometer progress chart and statistics

📈 See driving patterns, plan service intervals, and understand vehicle usage!

👥 Sharing with Family

Share your Gist ID and GitHub Token with family members. When they enter the same credentials, you'll all see the same vehicle logs!
